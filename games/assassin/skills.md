# 技能點法

捷徑欄位置有限。同一套點法很難同時把副本和對戰都點滿，所以分成兩套。

## 副本

目標是穩定疊起可消耗的資源，再用消耗技清完一群。

- 一格位移或衝刺，用來進場，也用來補資源。
- 一格範圍技，打到人就繼續疊資源。
- 一格消耗技，資源夠了就打出去。
- 自動戰鬥時，優先留會自己循環的組合，少留需要手動找背的招。

## 對戰

目標是先手打完能脫離。被集火時活著比多打一下重要。

- 留下隱身或突進到背後的那一格。
- 留下帶控制的範圍技，讓你多打一個回合。
- 留下能追也能跑的位移。
- 大招仍然用消耗技，但確認沒打中時還有路可以走。

## 共通

有資源就打消耗技，不要堆滿了還在平砍。刺客血量薄，輸出窗口很短，窗口結束就拉開距離。
